# OutRelMania Website

Statischer Frontend-Prototyp für GitHub Pages.

## Veröffentlichung
1. Alle Dateien in ein GitHub-Repository laden.
2. In GitHub unter Settings → Pages die Veröffentlichung aus dem Branch aktivieren.
3. Unter Settings → Pages → Custom domain deine vorhandene Domain eintragen.
4. Beim Domainanbieter die von GitHub geforderten DNS-Einträge setzen.

## Wichtig
Die Seiten für Registrierung, Chat, Forum und Spielersuche sind in diesem Paket als Frontend/Demo vorbereitet. Für echte Benutzerkonten, private Nachrichten, Forum-Posts, Moderation und dynamische Spielersuche braucht die Website zusätzlich ein Backend und eine Datenbank.
